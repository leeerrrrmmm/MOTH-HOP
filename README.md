# Moth Hop

**Moth Hop** is a mobile endless jumper game inspired by the classic **Doodle Jump**.

You control a moth that jumps from platform to platform, climbing higher and higher. The goal is to score as many points as possible without falling.

---

## About

Moth Hop is a Flutter-based arcade game built as a portfolio / pet project.
It focuses on smooth jump physics, endless level generation, and a clean, lightweight mobile experience.

### Key features
- Endless vertical gameplay
- Simple one-tap / tilt-style controls
- Procedurally generated platforms
- Score system
- Character selection carousel
- Sound & vibration settings

---

## Tech Stack

- **Flutter** & **Dart**
- Custom game loop
- Fixed timestep physics
- Object pooling (platforms, particles, etc.)
- `flutter_screenutil` for responsive UI
- Asset-based UI (no heavy external game engines)
